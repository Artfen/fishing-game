Slow Tide benchmark

Measures the game on this computer and graphics card: each scenario is set up the same way every time, then run for a few seconds while the frame rate, the 1% low, the graphics card's time per frame (where the browser allows), the game's simulation cost, draw calls and memory are recorded.

It runs in a save of its own: your game and your save are never read or written, and it never signs in. The results stay in this browser until you copy them. Close other tabs, plug a laptop in, and keep this window in front while it runs (each scenario reloads the page). It takes about half a minute per scenario.
